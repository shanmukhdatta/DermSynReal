# dermsynreal package

Future modules are deliberately implemented one phase at a time:
- `data/`: image manifests, provenance, hashes and group-aware splitting.
- `generation/`: checkpoint registry, morphology prompt templates, deterministic inference.
- `selection/`: quality, coverage, diversity and leakage-risk filters.
- `training/`: classifier factories, samplers, experiment runners.
- `evaluation/`: fixed real-test predictions, metrics, paired bootstrap.
- `reporting/`: saved tables, figures and quality-control galleries.

The package currently contains only a version marker.
